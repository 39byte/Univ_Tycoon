# 총합본 북진 작전

하나의 학교가 하나의 사단이 된다. 국방부의 명령으로 대학생들이 서리군단의 얼음 장막에 덮인 북녘을 향해 진군하는 3인칭 액션 RPG 웹 게임. 당신의 학과가 곧 당신의 무기다.

빌드 과정 없이 `index.html` 하나로 동작하며, 렌더링은 [three.js](https://threejs.org/) 0.160(CDN)을 쓴다.

## 실행

ES 모듈과 GLB를 불러오므로 `file://`로 열지 말고 정적 서버로 띄운다.

```
python -m http.server 8000
# http://localhost:8000
```

인터넷 연결이 필요하다(three.js를 jsDelivr에서 로드).

## 조작

| 입력 | 동작 |
|---|---|
| `WASD` | 이동 |
| 클릭 | 기본 공격 |
| `Shift` / `Space` / `K` | 회피 |
| `E` | 스킬 |
| `Q` | 궁극기 |
| 마우스 / 우클릭 드래그 | 시점 회전 |
| `Esc` | 일시정지 |

## 학과(캐릭터)

| 학과 | 캐릭터 | 직업 | 무기 |
|---|---|---|---|
| 글로벌스포츠산업학부 | 강하람 | 격투가 | 건틀릿 |
| AI데이터융합학부 | 서윤슬 | 저격 궁수 | 활 |
| 국가전략언어대학 | 마리카 정 | 창기병 | 창 |
| 언어인지과학과 | 한소리 | 언어 마법사 | 지팡이 |
| 자연과학대학 | 도연우 | 연금술사 | 플라스크 |
| 공과대학 | 백철민 | 해머 공병 | 해머 |

## 구조

```
index.html   게임 전체(HTML/CSS/JS)
asset/       Blender로 생성한 PBR 모델·텍스처·애니메이션 (자세한 내용은 asset/README.md)
```

## 크레딧

- 캐릭터 몸체·리그: Quaternius *Universal Base Characters*, 애니메이션: *Universal Animation Library* (CC0)
- 환경·무기·적 모델: Blender 스크립트(`asset/src/`)로 절차적 생성
